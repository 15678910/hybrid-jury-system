## 1. 이번 구간에 한 일과 이유

### 1-1. 서명 절차 진단 (`fbae810`)
- 신규 서명자가 「실시간 참가 현황」에 안 뜬다는 보고. Firestore `signatures` 16건(마지막 6/27), 6/27 이후 전화인증 신규 사용자 0 → **서명자가 SMS 인증을 통과하지 못한 것**이지 저장 실패가 아님. 서버 쪽(중복검사 엔드포인트·전화인증 설정·승인 도메인·App Check UNENFORCED)은 정상, 테스트 번호로 끝까지 성공(테스트 사용자는 삭제).
- 원인을 좁힐 수단이 없어 **클라이언트 실패 로그 `signup_errors`**를 넣었다(개인정보 없음: stage·code·message·ua·inApp·createdAt). 규칙은 create 전용·`hasOnly`·read 금지, 라이브에서 create 200/read 403/추가 필드 403 확인. 조회는 `cd functions && node read_signup_errors.cjs`.
- 인증요청 아래 안내문 추가(해외 발신 문자 차단 해제 → 크롬·사파리). 카카오 인앱 브라우저의 reCAPTCHA 실패 가능성도 로그로 확인할 것.
- Gemini `gemini-2.0-flash` 종료(404) → 5개 함수 `gemini-2.5-flash`로 교체·배포. 키는 `functions/.env`의 `GOOGLE_API_KEY`, 채팅에 절대 노출 금지.

### 1-5. 칼럼 초안 (미게시, 중단)
- 파일: `docs/columns/2026-09-21_5년_계획에_없는_5년_미래대응기금과_노르웨이의_두_개의_만.md` (8장, 국민연금 리밸런싱 유예 사례 포함).
- 새로 확인해 넣은 사실(다음에 카드·영상에 재사용 가능): 2026~2030 국가재정운용계획의 국세 415.4→584.4→606.7→625.5→644.8조(2027 +40.7%, 이후 연 3%대), 관리재정수지 △3.9%→△0.1%→△1.5%→△2.5%→△2.9%, 국가채무 1,413.8→1,734.1조(2027~2030 +214조), 국채 발행 축소 12.5조 = 162.3조의 7.7%. 5년 계획에 기금의 연도별 수지는 **없다**.

- 사용자와의 논의: 「기획예산처장관을 탄핵하라」 제목은 권하지 않았다(헌법 제65조 사유 없음·여당 과반이라 실현 불가·결정자는 7.13 대통령). 대안으로 1인당 환산(162조 ≈ 318만 원/인, 국민연금 −180조 ≈ 780만 원/가입자, 강원 교부세 −3.1조 ≈ 200만 원/도민)과 「국회가 지금 할 수 있는 셋」(부수법안 지정 거부·5년 수지 제출·두 개의 「만」 삽입)을 제안. 그 직후 사용자가 **중단** 결정.

## 4. 이 구간의 실수와 교훈
- Bash heredoc `\\n` 문제로 빌드가 깨진 채 옛 dist가 배포됨 → 데이터 패치는 Write 스크립트, 배포 전 「✓ built」 확인(1-2).
