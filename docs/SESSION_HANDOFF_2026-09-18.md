## 1. 이 세션에서 결정한 것과 이유

### 1-1. 모션 엔진 — wide(16:9) 모드와 diff 장면 (`scripts/motion/engine.html`)
- **wide 모드** (`--wide`, 1920×1080): 참고 영상(하라리 해설 유튜브)의 문법 — 검정·보라 바탕, 주황 포인트, 왼쪽 선화(9종 stroke 애니메이션: scale·key·vault·building·ballot·coins·split·map·catapult), 하단 자막 띠, 진행 바. 새 장면 `chapter`·`compare`·`source`·`diff`. 기존 장면은 가로 크기로 자동 축소.
- **compare 의 `cues`**: 낭독문 속 단서 낱말의 위치(글자 비율)에 맞춰 카드가 나타나고 강조 테두리가 옮겨 간다. 이유: 시안에서 「무엇에 쓸 것인가」를 읽는 동안 테두리가 반대 칸에 있었다(사용자 지적). 글자 비율 기준이라 음성이 바뀌어도 맞는다. `effectCue` 로 효과 줄 등장 시점도 지정.
- **diff 장면**: 신·구조문대비표를 조문 하나 = 한 화면으로. `{-삭제-}` 빨간 취소선, `{+신설+}` 주황 강조, 낭독 cue(현행/개정안/쉬운 말로/효과)에 따라 어절이 밝아지고 칸 테두리가 옮겨 감. 원문 150자 넘으면 `dense`. 원문은 `budget/data/bills/2221047·52·53·54·56·57.txt` 의 대비표에서 띄어쓰기만 넣어 옮겼다(요약 금지 원칙).
- **law 장면 `citeFirst`**: 「헌법 제54조 제1항. 국회는 …」처럼 조항 번호를 먼저 보여 준다(사용자 요청, 낭독 순서와 일치).
- `--outro N --outro-db X`: 마지막 낭독 뒤 N초 동안 음악을 X dB 로 올려 엔딩. 주의 — ffmpeg `volume` 수식은 dB 가 아니라 선형 배율이라 `10^(dB/20)` 로 환산해 넣는다(처음에 dB 를 그대로 넣어 음악이 사라졌었다). `amix` 가 6dB 낮추므로 종료카드 `--music-db` 는 본편 outro 목표보다 6dB 낮게 준다.
- `append_endcard.py --music-ss T --music-db`: 본편이 멈춘 곡 위치부터 이어 튼다. 음악(2분 36초)이 영상보다 짧으면 본편은 `-stream_loop -1` 로 반복하고, 종료카드는 `T % 음악길이` 지점에서 시작.
- `--reuse-frames`: 프레임(silent.mp4)을 재사용하고 음성·음악만 다시 믹스. 16:9 프레임 렌더가 12분물 기준 40분이라 음악 교체·볼륨 조정 때 필수. 단 화면 시간이 바뀌면(음성 교체) 다시 렌더해야 한다.
- essay 영상은 첫 프레임이 검어 사이트에서 「미게시」처럼 보였다 → `extra.poster` 지원(4.6초 프레임 JPG). 앞으로 essay 편은 포스터를 같이 만든다.
