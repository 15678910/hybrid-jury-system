### 1. CI 가 3주 넘게 죽어 있었다 (가장 중요)

`.github/workflows/ci.yml` 의 텔레그램 알림 메시지 줄들이 1열에서 시작해
`run: |` 블록 스칼라가 거기서 끊겼다. **유효한 YAML 이 아니어서 모든 실행이 잡 0개짜리
startup_failure 로 끝났다** — 빨간 X 는 떴지만 vitest·판례 파서·예측 계산 검증은
단 한 번도 실행되지 않았다.

고친 뒤 드러난 두 번째 문제: `precedent_parser.test.cjs` 와 `predictionMath.test.mjs` 는
vitest 스위트가 아니라 `node` 로 돌리는 독립 스크립트인데 끝에서 `process.exit()` 를
부른다. vitest 는 이를 오류로 본다. `vite.config.js` 의 `test.exclude` 에서 뺐다.

**현재 상태**: 113건 통과, 파서 43건 통과, 예측 계산 16건 통과.
`claude/**` 브랜치도 push 트리거에 넣었으므로 이제 작업 브랜치에서 검사가 돈다.

> ⚠️ **남은 것**: 텔레그램 알림이 `401 Unauthorized` 를 받는다. `TELEGRAM_BOT_TOKEN`
> 시크릿이 만료·폐기됐다는 뜻이다. CI 실패 알림이 전달되지 않는다.
> 데스크탑에서 봇 토큰을 재발급해 GitHub Secrets 에 다시 넣어야 한다.

### 2. 칼럼 통계 — 원 출처 확인 완료

앞 세션에서 「원 출처 미확인」으로 남겨 둔 것이 해소됐다.

- **출처 = 대검찰청이 국회에 제출한 국정감사 자료** (디지털타임스·한국NGO신문이 명시)
- **2021·2025년도 같은 계열이다** — 2024년 10월 보도(이투데이)와 최근 보도(디지털타임스)가

- 같은 자료에서 **보완수사 요구 7,508건(2021) → 17,122건(2025)** 을 찾아 본문에 추가.
  「검찰이 일을 덜 해서 기소율이 낮다」는 반론을 미리 막는다

**한계**: 언론사 원문에는 직접 접근하지 못했다(원격 환경의 외부 접속 차단, 주요 언론
도메인이 전부 egress 차단). 자료를 제출받은 의원실도 미확인. **데스크탑에서 기사 원문을
한 번 열어 재확인할 것.**

### 3. 상담료 절 신설 — 사용자 지적에서 나온 것

> 「시간당 변호사 상담료가 정해지지 않아 매우 심각합니다. 무료에서부터 1백만 원까지
> 있다는 것이 현실입니다」

기존 「다섯」 절은 **왜 안 내려가는가**(면허 독점·신뢰재·급박성)에 답했는데,
그보다 앞선 층이 빠져 있었다 — **값이 비싼 것이 아니라 값이 없다.**

| 경로 | 값 |
|------|------|
| 법률구조공단·마을변호사·로펌 초기 상담 | 0원 |
| 전화 상담 | 5만~10만 원 |
| 대면 상담 | 10만~30만 원 이상 |
| 대형 로펌 타임차지 | 시간당 수십만 ~ **200만 원** |

- 「다섯」 새 하위 절 — 가격의 분산이 아니라 **부재**. 그 비용은 반복 거래하는 기업이
  아니라 평생 한 번 변호사를 찾는 사람에게 집중된다. 값을 모르면 **묻는 일 자체를 포기**한다
- 「일곱」 새 하위 절 — **상담료는 수임액 보고(변호사법 제28조의2)에 잡히지 않는다.**
  사전 표시 의무 / 무료 창구 통합 공표 / 이의신청 안내 서식(제245조의6)에 무료 창구 병기

**한계(각주 ⑩)**: 상담료 공식 통계는 **존재하지 않는다.** 수치는 로펌·법률 포털 안내값이다.
그리고 그 부재 자체가 이 절의 논점이다. 게시 전 지방변호사회·소비자원 자료로 근거를 올릴 것.
