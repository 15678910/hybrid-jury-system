# 파기의 「방향」을 어떻게 판정할 것인가 — 설계 메모

> 작성 2026-08-07. 규칙을 확정하기 **전에** 무엇을 판정할지와 무엇을 판정하지
> 않을지를 먼저 적어 둔다. 문언을 본 뒤에 정의를 바꾸면, 나온 결과에 맞춰
> 기준을 고른 것과 구별되지 않기 때문이다.

## 왜 방향인가

이 사건(한덕수·이상민 상고심)은 **쌍방 상고**다. 피고인 측도, 내란특검도
상고했다. 그래서 「파기」라는 한 단어가 정반대 두 가지를 뜻한다.

- 피고인 상고가 받아들여진 파기 → 원심의 **유죄** 부분이 깨진다
- 검사 상고가 받아들여진 파기 → 원심의 **무죄** 부분이 깨진다

방향을 모른 채 「파기 확률 22%」라고만 말하면, 그 22%가 피고인에게 유리한
것인지 불리한 것인지 알 수 없다. 예측으로서 절반만 말한 셈이다.

또한 이 값은 「어느 재판부가 어느 쪽에 기운다」는 관측을 검증 가능한 숫자로
바꾼다. 평판을 계수로 넣는 대신, 재임 기간의 방향별 인용률을 세면 된다.

## 판정할 범주

| 값 | 뜻 |
|---|---|
| `DEFENSE` | 피고인 상고를 받아들여 파기 (유죄 부분이 깨짐) |
| `PROSECUTION` | 검사 상고를 받아들여 파기 (무죄 부분이 깨짐) |
| `BOTH` | 쌍방 상고이유가 모두 일부 받아들여짐 |
| `NONE` | 파기 아님 (상고기각 등) |
| `UNKNOWN` | 문언으로 가릴 수 없음 |

`UNKNOWN` 을 반드시 별도로 센다. 애매한 것을 한쪽에 몰아넣으면 그 비율이
그대로 결론의 편향이 된다.

## 판정에 쓸 신호 (문언 확인 후 확정)

우선순위를 미리 정해 둔다. 문언을 보고 나서 순위를 바꾸려면, 왜 바꾸는지를
이 문서에 함께 적는다.

1. **주문의 파기 대상 문언** — 가장 강한 신호
   - 「원심판결 중 **무죄** 부분을 파기」 → `PROSECUTION`
   - 「원심판결 중 **유죄** 부분을 파기」 → `DEFENSE`
2. **주문의 상고기각 주체**
   - 「검사의 상고를 기각한다」가 있고 파기가 있으면 → 파기는 피고인 쪽
   - 「피고인의 상고를 기각한다」가 있고 파기가 있으면 → 파기는 검사 쪽
3. **이유의 상고이유 판단 문언**
   - 「검사의 상고이유 주장은 이유 있다」 → `PROSECUTION`
   - 「피고인의 상고이유 주장은 이유 있다」 → `DEFENSE`

셋이 서로 어긋나면 `UNKNOWN` 으로 두고 사람이 볼 목록에 남긴다.
억지로 하나를 고르지 않는다.

## 판정하지 않는 것

- **누가 이겼는가에 대한 가치 판단.** 무죄 부분 파기가 「나쁜 결론」이라거나
  유죄 부분 파기가 「좋은 결론」이라는 뜻이 아니다. 방향은 방향일 뿐이다.
- **대법관 개인의 표.** 소수의견을 낸 대법관이 누구인지는 집계하지 않는다.
  개인을 예측하지 않는다는 원칙 그대로다.
- **동기.** 왜 그런 결론에 이르렀는지는 판정 대상이 아니다.

## 표본의 한계 (미리 밝혀 둘 것)

- 수집 표본은 「본문에 전원합의체가 언급된 판례」에서 출발하므로 전수가 아니다.
- 법제처 판례 DB 는 공간(公刊)된 판례만 담고 있어 파기 사건 쪽으로 치우쳐 있다.
  집계된 소부 파기율 58.8% 대 사법연감 5.6% 의 괴리가 그 증거다.
- 따라서 방향별 **비율**은 쓰되, 절대 수준은 쓰지 않는다.
- 재임 기간으로 좁히면 표본이 더 작아진다. 몇 건인지 반드시 함께 표시한다.

## 검증 방법

1. 조사 스크립트(`functions/probe_reversal_direction.cjs`)로 실제 문언을 본다.
2. 본 문언을 픽스처로 삼아 테스트를 쓴다. **지어낸 문장으로 통과시키지 않는다.**
3. 규칙을 만든 뒤, 판정 결과를 표본 몇 건에 대해 사람이 직접 대조한다.
4. `UNKNOWN` 비율이 높으면 규칙이 아니라 표본을 의심한다 — 문언이 다양한 것이지
   규칙이 틀린 것이 아닐 수 있다. 그때는 범주를 늘리기보다 `UNKNOWN` 을 그대로 둔다.
