# 외출해서 작업하는 순서 (노트북·태블릿 → 데스크탑 Claude Code)

> 2026-08-08 작성. 목적: 밖에서도 **데스크탑의 터미널 Claude Code** 로 작업하기.
> 원리는 하나 — 노트북·태블릿은 **화면을 보는 창**이고, 일은 전부 데스크탑에서 일어난다.

---

## 0. 나가기 전에 (데스크탑에서 한 번)

- [ ] **데스크탑을 켜 둔다.** 끄면 접속할 수 없다
- [ ] **절전 해제** — 설정 → 시스템 → 전원 → 화면 및 절전 → 「절전 모드」를 **안 함**
      (화면 끄기는 그대로 둬도 접속에 지장 없다)
- [ ] 크롬 원격 데스크톱이 **Online** 인지 확인

작업하던 Claude Code 창은 **켜 둔 채 나가도 된다.** 원격은 화면만 끊길 뿐
데스크탑의 프로그램은 계속 돌기 때문에, 도착해서 그대로 이어받을 수 있다.

---

## 1. 접속 (노트북·태블릿)

1. 크롬에서 **`remotedesktop.google.com/access`**
2. 「Remote devices」의 **`내-K-VOTE-PC`** 클릭
3. **PIN** 입력
4. 위쪽 모니터 탭에서 **하나만** 선택 (`LG FHD` 또는 `S22C450`)
   → 두 대를 같이 보면 글씨가 절반 크기가 된다
5. **`F11`** 로 전체 화면 — 노트북 작업표시줄이 사라져 오조작을 막는다

여기서부터 화면에 보이는 모든 것은 **데스크탑의 것**이다.

---

## 2. Claude Code 열기

**A. 이미 켜져 있으면** — 작업표시줄의 터미널 아이콘(`>_`)을 클릭.
창 제목에 작업 이름이 남아 있다. 이전 대화가 그대로 이어진다.

**B. 새로 켜야 하면**

1. 작업표시줄의 **탐색기**(노란 폴더) 클릭
2. 왼쪽 **바탕 화면** → **`hybrid-jury-system`** 폴더로 들어간다
3. 위쪽 **주소창을 클릭** → **`powershell`** 입력 → 엔터
4. 검은 창에 **`claude`** 입력 → 엔터

> 탐색기 왼쪽에 `Google Drive (G:)`, `컬럼`, `형사소송법` 이 보이면 데스크탑 것이 맞다.

> **창이 안 보이면 다른 모니터를 확인한다.** 데스크탑은 모니터가 두 대(`LG FHD`·`S22C450`)인데
> 원격에서는 한 번에 한 대씩 본다. 방금 연 창이 안 보는 쪽에 열렸을 수 있다.
> 위쪽 모니터 탭을 바꿔 확인하고, 창을 옮기려면 `Win + Shift + ←` / `→`.
> 작업할 창을 한쪽 모니터에 모아 두면 탭을 오갈 일이 없다.

---

## 3. 제대로 열렸는지 확인 (의심스러울 때만)

```powershell
hostname
```

| 결과 | 어디 |
|---|---|
| `DESKTOP-1PLMHMN` | 🖥️ 데스크탑 ✅ |
| `DESKTOP-GOLPA77` | 💻 노트북 ❌ — 창을 닫고 원격 화면 **안쪽**에서 다시 |

Claude Code 안에서는 화면 상단의 경로(`~\Desktop\hybrid-jury-system`)로도 확인된다.

---

## 4. 작업 시작 첫 마디

```
최신 docs/SESSION_HANDOFF_*.md 를 읽고 이어서 작업하자.
지금 브랜치와 origin 상태도 확인해줘.
```

새 세션은 이전 대화를 모르므로 인수인계 문서로 이어 붙인다.

---

## 5. 작업 중 지켜야 할 것

- **배포는 반드시 `claude/appeal-column-5hwjiy` 에서.** `main` 으로 배포하면
  오늘 작업이 사라진다 (2026-08-08 에 한 번 겪었다)
- **`public/` 에 파일을 넣으면 그 세션이 보고 커밋한다.** 예전 방식 그대로다
- 사용자 승인 없이 `firebase deploy` 금지 (CLAUDE.md)

---

## 6. 마칠 때

- [ ] 커밋·push 됐는지 확인 — **push 하지 않으면 데스크탑에만 남는다**
- [ ] Claude Code 창은 **닫지 않아도 된다.** 다음에 접속하면 그대로 이어진다
- [ ] 원격 창만 닫으면 된다. 데스크탑은 계속 켜 둔다

## 헷갈리기 쉬운 것 두 가지

### ① 브라우저로 연 세션은 데스크탑 앞에서도 「원격」이다

| 여는 방법 | 도는 곳 | 폴더가 보이나 |
|---|---|---|
| **Claude 데스크탑 앱** | 그 컴퓨터 | ✅ |
| **터미널에서 `claude`** | 그 컴퓨터 | ✅ |
| 브라우저 `claude.ai/code` → 사이드바에서 세션 클릭 | 클라우드 | ❌ |

데스크탑 앱과 터미널은 생김새만 다를 뿐 둘 다 그 컴퓨터에서 돈다. **평소 쓰는 것은 데스크탑 앱**이다.

데스크탑 화면에 들어갔다고 자동으로 데스크탑 세션이 되는 것이 아니다.
그 화면에서 **브라우저를 열어 대화를 이어 열면 클라우드**로 간다.
구분법은 하나 — **주소창이 보이면 브라우저(클라우드), 안 보이면 앱(로컬).**

### ② 클립보드·파일은 두 컴퓨터 사이를 오가지 않는다

크롬 원격이 보내는 것은 **화면 그림과 마우스·키보드**뿐이다.

- 💻 노트북에서 캡처 → 💻 노트북 창에만 붙는다
- 🖥️ 데스크탑에서 캡처 → 🖥️ 원격 안의 창에만 붙는다

**캡처한 컴퓨터와 대화창이 있는 컴퓨터가 같아야 한다.**

파일을 실제로 옮기려면 구글 드라이브·카톡·이메일 같은 중간 통로가 필요하다.

## 권장 배치 — 탭 두 개

노트북 크롬에 탭을 두 개 두고 쓴다.

| 탭 | 용도 |
|---|---|
| **Remote Access** | 데스크탑에서 실제 작업 |
| **Claude** | 질문·상의 · 노트북 화면 캡처 첨부 |

작업은 원격 탭에서, 캡처가 필요한 대화는 노트북 탭에서.
