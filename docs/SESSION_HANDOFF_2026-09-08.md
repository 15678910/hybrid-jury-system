## 1. 결정과 이유

### 1-1. 공소청 직제안 카드뉴스 7단계 (`prosecution-office-org-2026`)
- 법무부 9.4 입법예고(마감 9.9) 보도자료 PDF 를 받아 6쪽 전문을 추출해 대조했다. 스크린샷 5번의 「사법통제부에 재배당」 문구는 보도자료 4쪽 원문으로 확정.
- **가장 단단한 근거는 검사정원법 제1조**: 검사 정원 2,292명은 **법률**이라 대통령령(직제)으로는 못 줄인다. 그래서 6단계 제안을 「정부가 검사정원법 개정안을 낸다」로, 7단계 질문도 그렇게 맞췄다.
- 6단계 정원 항목은 **사용자 결정 (a)**: 검사 3분의 1 이상 감축(2,292→1,528 이하) 명시 + 일반직 8,414명 중 공소청 2,294명만 남기고 6,120명 경찰청 전환 배치. 검찰 수사관→경찰 전환은 임용 근거가 필요해 「중수청처럼 희망자 무시험 임용령을 함께」 한 줄을 붙였다. 조국혁신당의 같은 요구(9.6)는 참고 한 줄만.
- 카드 PNG 는 **로컬 Chrome 헤드리스**(`scripts/render-cardnews.sh`)로 뽑았다. 1600×1200 이 잘리지 않음을 기존 카드와 대조해 확인.

### 1-2. AI 1분 개벽늬우스 (AI 음성 뉴스) — `scripts/gen_news.py`
- 대본 `scripts/news-scripts/<slug>.json`, 세그먼트별 음성 → 카드 화면 + 자막 + 음악 베드. 엔진: `edge`(기본·무료) / `elevenlabs`(API 키) / `polly`(AWS) / **`--voice-dir`**(외부에서 받은 문장별 mp3).
- **라이브 두 편(수사준칙·직제)은 ElevenLabs 「현빈」 음성**이다. 사용자가 elevenlabs.io 에서 문장별로 받아 준 파일을 `--voice-dir` 로 넣었다. speakclone.vercel.app 은 열어 보니 **영어 학습 앱**이라 TTS 로 못 쓴다(사용자가 그렇게 알고 있었음).
- 제목 표기는 「AI 1분 개벽**늬우스**」, 배지 서체는 **Black Han Sans**(`scripts/fonts/blackhansans.ttf`, 대한늬우스풍 후보 5종 중 사용자 선택). 대본 JSON 의 `title`/`titleFont`.
- 화면 구성의 **최종 결정(같은 날 네 번 오간 끝)**: 영상 **안에** 「AI 1분 개벽늬우스」 배지(위) → 그 아래 **시리즈 제목 62px**(릴스 제목과 같은 크기) → 카드 → 하단 낭독 자막 **40px**. 사이트 카드 **밖**에는 같은 배지를 두지 않는다(릴스 카드만 「릴스」 오버레이). 이유: 중복 제거 + 공유·다운로드 파일에도 브랜드가 남게.
- 마지막 문장은 물음표로 끝내 억양을 올린다(edge-tts 는 문장부호로 억양 결정).

### 1-3. 릴스 — `scripts/gen_reel.py`
- 카드 7장 → 세로 45초, 카드에만 줌(전체 줌은 전환 중 글자 겹침). 음악 `public/music.mp3`(사용자 Suno 자작곡, 저작권 문제 없음 확인).
- **node-canvas 가 아니라 Pillow 인 이유**: `npm install ffmpeg-static` 이 미선언 canvas 를 지웠다(CLAUDE.md 09-03 사건). 파이썬 의존성은 `scripts/requirements-media.txt`.

### 1-4. 사이트 배선
- 카드뉴스 상세: `cardNews.js` 의 `news`/`reel` 필드 → 2단 임베드 + 「조문 분석 자세히 보기」 버튼. `/cardnews` 목록에 ▶영상 배지.
- `/videos` **「숏폼」 탭은 유튜브 없이** `cardNews.js` 의 news·reel 을 자동 표시(세로 플레이어, 「이 숏츠 보내기」·「저장」·상세 링크). 유튜브 업로드·관리자 등록은 **선택**이 됐다.
- 「이 숏츠 보내기」: 모바일은 Web Share API 로 **영상 파일을** 앱에 첨부, PC 는 링크 복사.
- 공유 바: Threads 는 `intent/post` 로 바로, 인스타·틱톡은 모바일 네이티브 공유(웹 공유 URL 자체가 없음).
- 종료 카드(`scripts/append_endcard.py`): 영상 끝 3초에 QR(punycode URL)+주소. SNS 영상 픽셀은 클릭이 안 되므로 유입은 QR·설명란 링크·프로필 링크로만 가능하다.

### 1-5. 영상 캐시 규칙 (⚠️ 반복 실수)
- 영상 파일을 같은 경로에 덮어쓰면 **브라우저·CDN 이 옛 영상을 계속 보여준다**(Cache-Control 이 no-cache 여도 `<video>` 는 자주 캐시). 라이브가 정상인데 「안 바뀌었다」는 보고가 두 번 있었다.
- 규칙: `cardNews.js` 의 영상 경로에 붙은 `?v=YYYYMMDDx` 를 **영상을 갱신할 때마다 올린다**. 현재 news `?v=20260908e`, reel `?v=20260908`.

## 2. 틀렸다가 바로잡은 것

- **「제목」·「로고」 지칭을 세 번 잘못 읽었다.** 화면에 후보가 넷(배지 / 배지 아래 시리즈 줄 / 하단 낭독 자막 / 카드 아래 HTML 제목)이라 매번 영상을 다시 뽑았다. 다음부턴 **어느 글자인지 화면 좌표로 확인한 뒤** 렌더한다. 자막 40→62→40, 배지 안→밖→안으로 오갔다. 최종은 §1-2.
- **ElevenLabs 수동 수집(다운로드 폴더 시간순) 실패 1회**: 9개 중 8개만 오고 같은 길이 파일이 둘. 사용자가 「1번 문장이 빠졌다」고 알려 줘 8+1 로 재구성했다. 다음 시리즈부터는 **문장 번호로 파일명(1.mp3~9.mp3)을 사용자가 직접 붙이는 방법 A** 를 권한다. 시간순 수집(방법 B)은 재생성·중복에 취약하다.
- 텔레그램 미리보기에 이미지가 안 나온 것은 서버가 아니라 **텔레그램 캐시**였다(태그·이미지 모두 정상). `@WebpageBot` 에 주소를 보내면 갱신된다.
- `public/158kb로고.jpg` 는 로고가 아니라 홍보 카드다. 사이트 로고는 헤더의 「⚖️ 사법개혁」 텍스트뿐.
