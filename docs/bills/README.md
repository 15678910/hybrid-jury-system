### ⚠️ 위원장 대안에는 심사보고서가 붙어 있지 않다

공포된 법의 본체는 위원장 대안인데, **대안 자체에 걸린 문서는 의안원문·위원회제출안·회의록뿐이다.**
심사보고서와 검토보고서는 **그 대안에 반영되고 폐기된 원안들** 쪽에 붙어 있다. 대안만 보고
「보고서가 없다」고 결론내면 1차 근거를 통째로 놓친다.

`2212965_정부조직법_일부개정법률안(김병기의원_등_166인)_검토보고서` 의

**11개 법률의 개정사항이 추가되어야 한다**고 적는다. 검찰 부분만의 숫자가 아니다 —

이 수치를 검찰 개편 규모로 옮겨 쓰지 말 것.

### 🚨 인용 규칙 — 원안 설명을 대안의 목적으로 적지 않는다

`reports/` 의 보고서는 **전부 원안(정부안·의원안)의 것**이다. 공포된 법은 대안이고,
둘의 내용은 같지 않을 수 있다. 원안 설명을 공포된 법의 목적으로 옮겨 적는 것은
CLAUDE.md 「2026-03-18 사건 — 법률 정보 부정확」과 같은 종류의 오류다.

확인된 사례: `2217197_공소청법안(정부)_심사보고서` 는 대안의 내용을 설명하지 않는다.
「5. 소위원회 심사내용」이 「개정안을 반영하여 ... 대안을 제안하기로 하고」로 끝나고,
「6. 찬반토론의 요지」는 **「회의록 참조」** 한 줄이다. 무엇이 어떻게 바뀌었는지는
이 문서에 없다.

| 상황 | 해야 할 것 |
|---|---|
| 보고서를 인용할 때 | **의안번호와 제안자를 함께 표기.** 「심사보고서에 따르면」만 쓰지 않는다 |
| 그 설명을 **공포된 법의 목적**으로 옮길 때 | `originals/` 의 **회의록 또는 대안 제안이유로 별도 확인** 후 옮긴다. 확인 못 하면 원안 설명으로만 적고 대안 쪽은 빈칸 |
| 원안과 대안이 다른 대목 | 어느 쪽 서술인지 **문장 안에 명시** |

각 `.txt` 머리의 `의안번호`·`법안명` 을 그대로 인용에 쓰면 된다.
`originals/` 파일에는 `역할` 줄에 **원안/대안**이 찍혀 있다.

### 실제로 얼마나 다른가 — 원문 대조 결과 (2026-08-16)

이건 이론적 주의가 아니다. 정부 원안과 공포된 법을 대조했더니 아래가 나왔다.
대조 방법은 `originals/` 의 원안 의안원문 텍스트와 `docs/bills/` 의 공포법 원문을
`grep` 으로 맞춰 본 것이고, 공포법 쪽은 법령정보센터 원문을 기준으로 삼았다.

**① 공소청법 — 조직 명칭이 통째로 바뀌었다**

| 용어 | 정부 원안 2217197 | 공포된 법 |
|---|---|---|
| 대공소청 | 31회 | **0회** |
| 고등공소청 | 49회 | **0회** |
| 광역공소청 | 0회 | **32회** |
| 지방공소청 | 40회 | 28회 |

원안은 **대공소청 / 고등공소청 / 지방공소청** 3층이었고, 공포된 법은
**공소청 / 광역공소청 / 지방공소청** 이다. 원안 자료를 그대로 인용하면
**존재하지 않는 기관 이름**을 쓰게 된다.

**② 공소청법 — 원안 제62조(직무배제 요구)가 공포된 법에 없다**

원안 제62조는 사법경찰관리등이 부당한 행위를 하면 지방공소청장이 **수사 중지를 명하고
소속 기관장에게 직무배제를 요구**할 수 있게 했고, 요구받은 기관장은 정당한 사유가
없으면 배제하여야 한다고 정했다. 공포된 공소청법에는 「직무배제」·「수사 중지」가
**0회**다. 이 조항은 대안에 반영되지 않았다.

> `police-power-concentration` 쟁점에서 이걸 놓치면 정반대로 적게 된다.
> 원안만 읽으면 「공소청이 사법경찰에 대한 직무배제 요구권을 가진다」고 쓰겠지만,
> 공포된 법에는 그런 권한이 없다.

**③ 중수청법 — 권한남용 금지는 「신설」이 아니라 「이동」이다**

원안 **제41조**(제5장 소속 공무원의 직무수행)에 있던 권한남용 금지 조항이
공포된 법에서는 **제5조**(제1장 총칙)로 올라갔다. **문언은 같다.**
조문 목록만 비교하면 총칙에 새로 생긴 것처럼 보이지만 신설이 아니다.

**④ 조문 번호가 어긋난다**

중수청법은 앞쪽에서 한 조씩 밀렸고(원안 제6조 중대범죄수사청장 → 공포법 제7조),
공소청법은 뒤쪽이 밀렸다(원안 제63조 항고 및 재항고 → 공포법 제57조).
**원안 조문번호로 공포된 법을 인용하면 다른 조문을 가리킨다.**

### 근거의 세 층 — 목적을 적을 때 어디서 가져오는가

공포된 법에 얼마나 가까운가로 층이 갈린다. 설계문서 Ⅱ 「근거의 세 층」이 정본이고,
여기서는 **어느 폴더가 몇 층인지**만 적는다.

| 층 | 무엇 | 어디에 |
|---|---|---|
| **1** | **대안 제·개정이유** — 공포된 법 그 자체의 이유. 별도 확인 불필요 | `docs/bills/*_원문.txt` 의 「【 제·개정 이유 】」 절 |
| **2** | 원안 심사보고서·검토보고서 — 원안의 말. 대안 확인 전엔 공포법 목적으로 못 씀 | `reports/` |
| **3** | 회의록 — 심의 과정의 **발언**. 단독으로 목적을 확정하지 않는다 | `originals/회의록/` |

**1층이 있으면 1층을 쓴다.** 법제처가 붙인 제·개정이유는 대안 기준이라
`공소청법_원문.txt`·`중수청법_원문.txt` 안에 이미 들어 있고, 공소청법 쪽은
제정이유와 주요내용 가~카까지 전문이 실려 있다. 회의록까지 가지 않아도 된다.

회의록은 그 위에서 **「원안의 무엇이 왜 바뀌었는가」**를 짚을 때 쓴다 —
위 ①②처럼 조직 명칭이 바뀌고 직무배제 조항이 빠진 경위가 거기 있다.

공포된 법의 제·개정이유(법제처 제공)는 **대안 기준**이라 `docs/bills/공소청법_원문.txt`·
`중수청법_원문.txt` 의 「【 제·개정 이유 】」 절이 대안 쪽 근거로 바로 쓸 수 있다.

### 분량이 큰 것부터 — 여기가 실제 근거다

| 문서 | 글자 수 | 무엇이 들어 있나 |
|---|---|---|
| `2217200_중대범죄수사청법안(정부)_검토보고서` | 176,375 | 중수청 전문위원 검토 전문 |

**심사보고서(위원회 의결 기록)는 대부분 1,300~4,300자로 짧다.** 정부안처럼 소위에 직접
회부된 건은 「3. 전문위원 검토보고의 요지 — 생 략(소위 직접 회부)」으로 끝난다.
쟁점의 실질은 **검토보고서** 쪽에 있다.

> 같은 검토보고서가 여러 의안번호로 중복 저장된 것이 있다(예: 176,375자 문서가 2217200·2203346
> 양쪽에). 여러 법안을 묶어 병합심사한 보고서가 각 법안 페이지에 서로 다른 bookId 로 걸리기
> 때문이다. 중복이 아니라 **같은 문서의 다른 게시 경로**다.

## 3. 왜 텍스트로 보관하는가

세션 환경에 따라 `likms.assembly.go.kr`·`law.go.kr` 등 국회·법령 사이트가
이그레스 정책으로 차단될 수 있다. 실제로 2026-08-03 세션에서 해당 도메인이
전부 프록시 403으로 막혀 원문 검증이 불가능했고, 그 결과 이미 코드에 기재된
조문 내용을 확인할 수 없는 상태가 발생했다.

원문 텍스트를 저장소에 두면 네트워크 없이도 `grep`으로 즉시 대조할 수 있다.

> **PDF 원본은 저장소에 올라가지 않는다.** `.gitignore` 에 `*.pdf` 가 걸려 있어
> `reports/*.pdf` 는 **수집한 기기에만** 남는다. 저장소를 새로 복제한 세션(원격 세션 포함)에는
> `.txt` 만 도착한다. 표·서식이 걸린 대목을 원본으로 되짚어야 하면 데스크탑에서
> `node collect_bill_reports.cjs --fetch` 를 다시 돌리면 된다 — `_수집로그.json` 에
> 문서마다 `bookId` 와 다운로드 URL 이 남아 있으므로 같은 파일이 그대로 다시 받아진다.

## 4. 사용법

```bash
# 특정 조문 확인
grep -o "제245조의6[^\"]\{0,400\}" docs/bills/2220257_법사위안_추출텍스트.txt

# 특정 단어의 등장 여부·횟수 (예: 법률 전문에 「국선」이 있는가)
grep -c "국선" docs/bills/2220257_법사위안_추출텍스트.txt

# 심사자료 전체에서 쟁점어 찾기 (어느 보고서의 몇 번째 줄인지 함께 나온다)
grep -rn "과학수사" docs/bills/reports/*.txt

# 다시 받기 (데스크탑 세션에서만 — 원격은 도메인이 막힌다)
cd functions && node collect_reform_laws.cjs --fetch
cd functions && node collect_bill_reports.cjs --fetch
```

## 5. 원문 대조로 확인된 사실

### 형사소송법 2220257 (2026-08-03 확인)

- **「국선」 0회, 「법률구조」 0회** — 법률 전문에 조력 관련 단어 없음
- **제245조의6 후단 신설**: 「이 경우 사법경찰관은 불송치 등의 결정서와
  제245조의7에 따른 이의신청에 대한 안내 및 서식을 함께 보내야 한다」
- **제245조의7 개정**: 종전 제2항(자동 송치)이 **제4항으로 이동**,
  제2항(고발인 이의신청)·제3항(이의신청 기간 제한) 신설
- **제245조의7 제3항 신설**: 이의신청은 통지받은 날부터 **3개월 이내**
  (정당한 사유 시 송부일부터 6개월 범위에서 연장) — 현행법에는 없던 기간 제한
- **제245조의12 제6항**: 열람·등사 기록의 사용목적 위반 시
  **1년 이하 징역 또는 500만원 이하 벌금**
- **제260조**: 재정신청 관할이 고등법원 → **지방법원 본원 합의부**로 변경
- **시행일**: 2026년 10월 2일 (일부 조항은 부칙 제1조 각 호에 따라 별도)

### 공소청법·중수청법 (2026-08-16 확인)

- **검찰청 폐지의 근거는 공소청법 부칙 제2조**다 — 「검찰청법은 폐지한다」.
  법령정보센터가 이를 별도 「검찰청법(타법폐지)」로 표시하기 때문에
  `검찰청법_20261002시행.txt` 의 본문이 그 한 줄뿐이다.
- **공소청법 시행일**: 2026-10-02. 다만 제41조는 공포일(2026-03-24) 시행.
- **중수청법 시행일**: 2026-10-02. 제9조·제33조는 공포일, **제19조제4호만 2028-10-02**.
- 공소청법·중수청법 원문에는 **제정이유와 주요내용 전문이 함께 들어 있다.**
  설계문서 Ⅱ-2가 요구한 「목적·역할의 1차 근거」가 심사보고서 없이도 일부 확보된다.
- **대검 과학수사부의 하부조직**은 검찰청 사무기구에 관한 규정 **제9조의2**에 있다 —

  시행규칙 제42조가 원장·지방과학수사연구소장·분원장 체계를 정한다.

### 경찰법 제16조(국가수사본부장) — 2026-08-17 확인

「국가수사본부」는 경찰법에 **14회** 등장하고, 조직의 근거는 **제16조**다.

| 항 | 내용 |
|---|---|
| ① | 경찰청에 국가수사본부를 두며, **국가수사본부장은 치안정감**으로 보한다 |
| ② | 「형사소송법」에 따른 경찰의 수사에 관하여 **시·도경찰청장·경찰서장 및 수사부서 소속 공무원을 지휘·감독** |
| ③④ | 임기 **2년, 중임 불가**. 임기가 끝나면 당연퇴직 |
| ⑤ | 직무집행상 헌법·법률 위배 시 **국회의 탄핵소추 의결 대상** |
| ⑥ | 외부 모집 시 자격 5호 (수사업무 10년, 판사·검사·변호사 10년 등) |
| ⑦ | 외부 모집 시 결격 5호 (정당 당적 이탈 3년 미만, 판사·검사 퇴직 1년 미만 등) |

제17조제1항·제2항이 국가수사본부장을 경찰청 하부조직 체계 안에 둔다.

> `police-power-concentration` 쟁점에서 볼 대목은 **제2항의 지휘·감독 범위가
> 「형사소송법에 따른 경찰의 수사」로 한정**돼 있다는 것과, **제5항이 탄핵소추 대상**으로
> 못 박았다는 것이다. 둘 다 조문에서 읽은 사실이다.
> 이 통제가 충분한가는 **정책 판단**이므로 여기 적지 않는다 (설계문서 Ⅱ-4).

> 아래 사실들은 **조문에서 직접 읽은 것**이고, 「어느 조직으로 옮기는 것이 옳은가」 같은
> 판단은 여기에 적지 않는다. 설계문서 Ⅱ-4에 따라 사실 확인과 정책 판단은 섞지 않는다.
