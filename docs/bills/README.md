법률·정책 내용을 코드나 칼럼에 기재하기 전에 **반드시 이곳의 원문과 대조**한다.

## 보관 파일

| 파일 | 내용 | 출처 |
|------|------|------|
| `2220257_법사위안_추출텍스트.txt` | 형사소송법 일부개정법률안(법제사법위원장 대안), 2026.7.31 본회의 통과 | 국회 의안정보시스템 PDF에서 텍스트 추출 |

## 왜 텍스트로 보관하는가

세션 환경에 따라 `likms.assembly.go.kr`·`law.go.kr` 등 국회·법령 사이트가
이그레스 정책으로 차단될 수 있다. 실제로 2026-08-03 세션에서 해당 도메인이
전부 프록시 403으로 막혀 원문 검증이 불가능했고, 그 결과 이미 코드에 기재된
조문 내용을 확인할 수 없는 상태가 발생했다.

원문 텍스트를 저장소에 두면 네트워크 없이도 `grep`으로 즉시 대조할 수 있다.

## 사용법

```bash
# 특정 조문 확인
grep -o "제245조의6[^\"]\{0,400\}" docs/bills/2220257_법사위안_추출텍스트.txt

# 특정 단어의 등장 여부·횟수 (예: 법률 전문에 「국선」이 있는가)
grep -c "국선" docs/bills/2220257_법사위안_추출텍스트.txt
```

## 2220257 대조로 확인된 주요 사실 (2026-08-03)

- **「국선」 0회, 「법률구조」 0회** — 법률 전문에 조력 관련 단어 없음
- **제245조의6 후단 신설**: 「이 경우 사법경찰관은 불송치 등의 결정서와
  제245조의7에 따른 이의신청에 대한 안내 및 서식을 함께 보내야 한다」
- **제245조의7 개정**: 종전 제2항(자동 송치)이 **제4항으로 이동**,
  제2항(고발인 이의신청)·제3항(이의신청 기간 제한) 신설
- **제245조의7 제3항 신설**: 이의신청은 통지받은 날부터 **3개월 이내**
  (정당한 사유 시 송부일부터 6개월 범위에서 연장) — 현행법에는 없던 기간 제한
- **제245조의12 제6항**: 열람·등사 기록의 사용목적 위반 시
  **1년 이하 징역 또는 500만원 이하 벌금**
- **제260조**: 재정신청 관할이 고등법원 → **지방법원 본원 합의부**로 변경
