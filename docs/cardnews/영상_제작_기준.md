# 영상 제작 기준 (모션뉴스·해설편·essay)

영상을 새로 만들거나 다시 뽑을 때 이 기준을 바꾸지 않는다. 바꿔야 하면 사용자 승인을 받고 이 문서를 먼저 고친다.

## 1. 배경음악 — 「본편은 낮게, QR 이 나올 때 올렸다가 줄이며 끝」

| 구간 | 음악 | 비고 |
|---|---|---|
| 시작 | 1~1.5초 페이드인 | |
| 본편 | **낮게 깐다** | 글자·낭독을 가리지 않게 |
| 본편 마지막 2~3초 | **1초 동안 올린다** | 종료카드(QR)가 나올 때 가장 크게 |
| 종료카드 3초 | **올린 음량 그대로 이어서**, 마지막 1.5초 페이드아웃 | 본편 음악이 멈춘 지점부터 이어 튼다(`--music-ss`) |

**금지**: 본편 끝에서 음악을 줄였다가 종료카드에서 다시 작게 시작하는 것(2026-09-30 「한 사람의 위원회」 첫 판이 이렇게 나와 사용자 지적을 받았다 — essay 무낭독 모드가 `--outro` 를 무시하고 본편 끝에서 페이드아웃했던 탓. 지금은 고쳐져 있다).

### 들리는 음량을 맞추는 값

낭독이 있으면 `amix` 가 음악을 6dB 낮춘다. 그래서 명령에 주는 값이 모드마다 다르다. **귀에 들리는 음량**은 두 모드가 같아야 한다(본편 ≈ -20, 엔딩·종료카드 ≈ -10).

| 모드 | 본편 `--music-db` | 엔딩 `--outro N --outro-db` | 종료카드 `append_endcard.py --music-db` |
|---|---|---|---|
| 낭독 있음 (해설편·essay 낭독) | `-14dB` | `--outro 3 --outro-db -4` | `-10dB` (= outro-db − 6) |
| 낭독 없음 (`--silent` essay) | `-14dB` | `--outro 2 --outro-db -10` | `-10dB` (= outro-db 그대로) |

### 명령 예 (낭독 없는 essay)

```bash
python scripts/gen_motion_news.py --slug <slug> --silent --music public/music.mp3 \
  --music-db=-14dB --outro 2 --outro-db -10
python scripts/append_endcard.py --in reels/<slug>-motion.mp4 --slug <slug> \
  --out public/cardnews/<slug>/motion.mp4 --music public/music.mp3 --music-ss <본편 초> --music-db=-10dB
```

음악만 바꿀 때는 `--reuse-frames` 로 프레임을 다시 그리지 않는다.

**확인법**: 마무리 전에 구간 음량을 잰다 — 본편보다 종료카드 직전·종료카드가 4~6dB 커야 하고, 마지막 0.3초는 크게 작아야 한다.

```bash
ffmpeg -ss <초> -t 0.4 -i <영상> -vn -af volumedetect -f null - 2>&1 | grep mean_volume
```

## 2. 종료카드 — QR 필수

- 세로 영상은 **반드시** `append_endcard.py` 로 끝 3초에 QR + 주소(시민법정.kr/cardnews/<slug>) 종료카드를 붙인다. 빠뜨리지 않는다.
- QR 이 가리키는 페이지는 `cardNews.js` 에 등록·배포해야 생긴다. 게시 전 영상은 QR 이 빈 페이지를 가리킨다.
- 원격(리눅스) 세션에는 `scripts/fonts/notokr-*.ttf` 가 없다(.gitignore). 임시로 Pretendard 를 같은 이름으로 연결해 만들고 끝나면 지운다.

## 3. 제목 — 왼쪽 위에 끝까지

- 영상이 무엇에 관한 것인지 **어느 장면에서 멈춰 봐도 알도록** 배지(「AI 1분 개벽늬우스」) 아래 왼쪽에 제목을 상시 띄운다.
- essay 모드는 장면 JSON 의 `series` 에 제목을 넣으면 표시된다(두 줄은 `\n`). 비워 두면 표시되지 않는다(`engine.html` 의 `titled`).

## 4. 글자

- 한 장면에 핵심 한두 줄. 글자가 많으면 임팩트가 떨어진다(2026-09-30 사용자 지적 — 201초 24장면을 80초 14장면으로 줄였다).
- 장면 시간은 마지막 줄이 다 뜨고 1초 이상 머무르게 준다(`step × 줄 수 + 1초` 이상). 모자라면 마지막 줄이 뜨기 전에 넘어간다.
- 조문 화면은 원문 문구를 쓴다. 사용자가 서술형 등으로 바꾸라고 하면 따르되 장면 JSON `_comment` 에 원문 표현을 적어 둔다.
