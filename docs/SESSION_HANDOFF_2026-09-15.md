### 1-3. 모션 엔진 확장 (`scripts/motion/engine.html`, `scripts/gen_motion_news.py`)
- **essay 모드**(지식채널e풍): 검은 화면, 글자만, 내레이션 없음. 장면 유형 `lines`/`number`/`law` 추가. `--silent` 는 장면 `dur` 로 타임라인, `--essay` 는 같은 화면에 낭독을 얹음(화면 시간 = max(낭독, 장면 dur×0.85)).
- 왜: 지식채널e 「헌법 제1조」편(2010.7.12)의 문법 — 한 화면 한 문장, 조문 원문 인용, 질문으로 열고 같은 질문으로 닫기, 핵심 문장 앞 정적 — 이 우리 주제(「권력은 국민으로부터 나온다, 그런데 나와서 어디로 가지?」→「초과세수도 국민으로부터…」)와 맞아서.
- 참고 형식이 5분물이라 우리 것도 2분 33초(22화면)가 됐다. 「1분」 브랜드보다 길지만 사용자가 수용.

### 1-5. 배경음악 — 사용자가 직접 찾아 올리기로 함

## 2. 남은 일 (순서대로)

1. **배경음악 수령** → 1-5 ④.
2. **글자판 최종 렌더**
   ```bash
   python scripts/gen_motion_news.py --slug semiconductor-windfall-e --silent --music <음원>
   # 720p 재인코딩 → append_endcard.py --slug future-fund-key-2026 (QR 은 기금 시리즈 페이지로)
   # → public/cardnews/future-fund-key-2026/proposal-essay.mp4
   ```
   합성 트랙을 쓰려면 `reels/tmp-motion-semiconductor-windfall-e/spec.json` 을 `gen_percussion.py` 에 넣어 wav 를 만든 뒤 `--music` 에 준다. 이번 세션에서는 음원 교체가 잦아 영상만 먼저 뽑고(`-an` 대신 anullsrc 무음 트랙 필요 — append_endcard 가 오디오 스트림을 요구함) 오디오를 나중에 `ffmpeg -map 0:v -map 1:a` 로 얹는 방식을 썼다.
3. **현빈 낭독판**: `scripts/audio/news-semi/1~22.mp3` 수령 → 길이 대조(글자수 대비 0.15~0.22초/자) →
   ```bash
   python scripts/gen_motion_news.py --slug semiconductor-windfall-e --essay --voice-dir scripts/audio/news-semi --music <음원> --music-db -12dB
   ```
   → 720p → endcard → `proposal-news.mp4`. 음성 원본은 `git add -f` 로 보관(다른 시리즈와 동일).
4. `cardNews.js` 의 `extra` 주석 해제, `?v=20260915a` → 실제 날짜로. `npm run build` → 로컬 프리뷰 → **사용자 승인** → `firebase deploy --only hosting` → 라이브 파일 크기 대조.
5. 20번 화면 줄바꿈 답 반영(1-4 미결).
6. (선택) 앞선 네 시리즈도 essay 모드로 재제작 가능. 대통령령편은 「40일이 5일이 됐다」, 직제편은 「지휘를 지운 정부가 통제로 되돌리는가」로 열면 된다.
