## 1. 결정과 이유 (이번 세션)

### 1-1. 수사절차 분석 문서 (`docs/analysis/수사절차_실패유형과_보완제도.md`)

- **§1 유형 ①·②를 갈래별로 갈라 다시 썼다** (§6.5-3 완료). 유형 ① = 서귀포서 A경위(2024)·서부서 B경사(2019~21, 17건 **반려** — 원래 유형 ②에 「허위 종결」로 있었으나 행위 실질이 반려라 옮김). 유형 ② = 서귀포서 교통조사팀 C경장(14건 조작) + A·B의 셀프 결재 + **별개 인물**인 실종팀 A경장(갈래 A). 동기 진술은 갈래 A만 보도 원문 확인됐음을 명시.
- **§6.4-8 신설 — 「지시만 있는 매뉴얼은 왜 작동하지 않는가」.** 사용자가 준 방송 화면(실종 수사 매뉴얼: 범죄 관련성 염두·통화돼도 직접 확인·과장/팀장 검토 후 해제)이 근거. 진단 넷(규범력·기록·결과·밖의 눈), 처방 넷(층위 상향+미입력 금지 / 시스템 강제 결재 / **신고자 자동 통지** / 통계 경보+콜백). 핵심 논리: **상급자 검토 의무는 종이 위에 이미 있었고 이미 뚫렸다** — 책임 서명 제안(§6.4-7)과 같은 결론의 두 번째 증거.
  - ⚠️ 매뉴얼 화면은 **원문 미확인**(§6.5-5). 정식 명칭·제정 시점·예규와의 관계 확인 필요.

### 1-3. 판결서 공개 쟁점 (`lawIssues.js` judgment-disclosure) + 카드 6장 (`docs/cardnews/판결서공개_6단계/`)

- 처음엔 조문이 저장소에 없어 **verdict 「검증 대기」**(새 라벨 신설)로 넣고 카드는 초안 표시로 만들었다. 데스크탑이 형소법·민소법·법원조직법 원문을 받아 push한 뒤 **「부분 성립」**으로 올리고 카드를 확정판으로 다시 뽑았다.
- 원문에서 확인된 핵심 (README 「판결서 공개」 절과 같음):
  - **민사가 형사보다 넓다** — 민소법 제163조의2는 「선고된」(미확정 포함, 2023.1.1~) + **검색어 제공 의무**(②). 형소법 제59조의3은 「확정」 한정, 검색 의무 없음. **두 조문 제목을 바꿔 쓰지 말 것** — 실제로 한 번 뒤집어 적은 일이 있다.
  - **법률 제21241호(2025-12-30 공포)가 형사 미확정 공개를 이미 입법** — 시행 2027-12-31(부칙 제1조), **2000-08-01 이후 선고 사건까지 소급**(부칙 제2조). 제·개정이유가 「알 권리」 명시. 이것이 이번 확인의 가장 큰 발견 → 제안을 「남은 것 완성」(시행 앞당기기·검색 의무 형사 확장·소액사건 포함·데이터/API·**일반인 불복**·사건번호 연계)으로 재구성.
  - 불복(제59조의3④⑤)은 소송관계인·이해관계인만 — 「누구든지」 열람하는 일반인에게 불복 없음.
  - 2026-10-02 개정은 제59조의3 불변(diff).

### 1-4. 이의신청의 문해력 문턱 (`lawIssues.js` objection-literacy-threshold, 성립)

- 배경: 사용자가 만든 무료 법률 AI **easylaw**가 「글을 쓸 수 있는 사람」까지만 돕는다는 문제의식. 정부 직영 AI 자동 작성안은 **이해충돌(상대방이 국가)·오류가 기각 근거로 되돌아옴**을 이유로 채택하지 않음 — rationale에 적어 둠.
- **결정적 조문 확인**: 입구는 **제237조**(고소·고발 「서면 또는 구술」, 구술이면 경찰이 서류 작성 의무)·제236조(대리고소)로 열려 있는데, 출구인 **제245조의7은 4개 항 어디에도 방식 규정이 없다**. 제245조의6 개정이 「안내 및 서식」 동봉 의무를 신설했으나 서식은 문해력을 전제한다.
- 제안 세 층: 구술 접수+조서 작성 의무 명문화 / 취약 피해자 사건 불송치 **자동 재검토(opt-out)** / 쉬운 언어 통지 + 무료 조력 안내 의무 + 절차조력인.
- ⚠️ 소액사건심판법 구술제소·진술조력인 근거 조문은 **미수집** — 카드·쟁점에 조문 번호 없이 「선례」로만 적었다.

### 6-2. 이번에 바로잡은 것과 함정

- **제안 ①을 고쳤다.** 「검색 의무를 형사에도 둔다」고 썼는데 제21241호가 이미 뒀다(개정 후 제59조의3②).
  제안은 「시행을 앞당긴다」로 좁혔다. 조문을 받기 전에 제안을 쓰면 이렇게 된다.
- **`target=law` 는 「현행」이 아니다.** 시행일이 단계별인 법은 마지막 단계가 온다.
  형소법에 이어 법원조직법에서도 확인 — `법원조직법_원문.txt` 제4조②는 「대법관 26명」인데
  이것은 2028-03-12 시행분이고 현행은 14명. 대조용은 반드시 `target=eflaw&efYd=` 로 받을 것.
  README 표에 ⚠️ 표시해 뒀다.
- **「형사는 확정돼야 열린다」는 2027-12-30 까지만 맞다.** 판결서 카드·칼럼에 이 문장이 있으면
  「지금」과 「2027-12-31부터」를 나눠 써야 한다.
- 경찰수사규칙은 2026-07-01 시행분(제629호)이 현행이고 10/2 형소법 개정에 맞춘 규칙 개정은
  검색에 아직 없다 — 나오면 제113조를 다시 볼 것.
