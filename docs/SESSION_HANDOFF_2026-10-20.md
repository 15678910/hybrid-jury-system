## 2. 인스타그램 — 사이트에서 바로 게시 + 토큰 자동 연장 (10.11)
- 사용자 요청 「아이콘 클릭으로 올리기」 → **관리자 전용 Cloud Function** 방식(사용자가 셋 중 선택). `publishInstagramReel`(asia-northeast3): 관리자 코드 확인 → `cardnews/<slug>/<file>.mp4` 만 허용 → 릴스 컨테이너 → 게시. `instagramPosts/<videoId>` 로 **중복 게시 차단**(409 → 사용자가 확인하면 force).
- 「토큰 갱신이 뭐냐」 → 60일 만료 토큰을 **매주 월 04:10 자동 연장**(`refreshInstagramToken`). 토큰은 **Firestore `instagramAuth/current`** 에 둔다 — `settings` 컬렉션은 공개 읽기라 쓰면 안 된다. 실패하면 텔레그램 알림.
- 「관리자 코드로 입력했는데 안 된다」 → /admin 은 작성자 코드도 받으므로 함수도 `isSiteAccessCode()` 로 **관리자·작성자 코드 둘 다** 허용.
- 「토큰이 없습니다」 → 사용자가 `.env` 에 IG 값을 넣지 않은 상태라, **사이트 아이콘에서 토큰을 붙여넣는 길**(`setInstagramToken`, `/me` 의 id 가 IG_USER_ID 와 같아야 저장)을 추가. 붙여넣은 뒤 재시도는 **force 없이** 다시 중복 검사를 거친다(안 그러면 두 번 올라간다 — 실제로 한 번 겪음).
- **남은 것**: 사이트 동영상 페이지 인스타 아이콘 → 코드 → Meta 앱 토큰 붙여넣기. 「이미 올라간 영상입니다」가 뜨면 정상. GitHub Actions 경로(`instagram-publish.yml`)는 여전히 Secret `IG_ACCESS_TOKEN` 을 쓰므로 **11월 말 만료** — 그때는 Secret 교체 또는 Actions 경로 폐기.
- 절차·함정은 `docs/instagram/README.md`. 토큰·키는 어디에도 적지 않는다.
