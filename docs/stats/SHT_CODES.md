# 사법연감 API — 표 코드(sht) 수집표

> **태블릿·휴대폰에서 브라우저만으로 채울 수 있는 문서입니다.**
> 터미널이 필요 없습니다. 값을 채우거나, 채팅으로 알려주셔도 됩니다.

## 어디서 찾나

1. [사법연감정보조회서비스](https://www.data.go.kr/data/15140048/openapi.do) 접속
2. 파란 **[데이터조회하기]** 버튼
3. 왼쪽 **API 목록**을 스크롤하며 표를 찾는다 (ㄱㄴㄷ 순)
4. 표를 누르면 제목 옆에 **`[코드 : T186083023536704]`** 형식으로 코드가 뜬다
5. 아래 표에 **표 이름 + 코드**를 적는다

> 화면 스크린샷을 채팅에 올려주셔도 됩니다. 코드를 옮겨 적는 것보다 그게 편하면 그렇게 하세요.

## 1순위 — 국선변호인 선정 사건표 (칼럼에 바로 사용)

목록의 **ㄱ 구간**에 있습니다. 화면에서 이미 확인된 표들입니다.

| # | 표 이름 (화면에 보이는 그대로) | sht 코드 | 비고 |
|---|---|---|---|
| 1 | 국선변호인 선정 사건표 상… | | 상고심으로 추정 |
| 2 | 국선변호인 선정 사건표 항… | | 항소심으로 추정 |
| 3 | 국선변호인 선정 사건표(제… | | 제1심으로 추정 |

**왜 필요한가**: 칼럼 「신청할 수 있다」는 말의 값의 나 홀로 재판 비율 수치가 지금은
**보도 인용**이라 편집 메모에 「재확인 권장」으로 남아 있다. 이 표에서 심급별 국선 선정
건수를 직접 뽑으면 **1차 자료 기반**으로 격상된다.

## 2순위 — 형사공판사건 / 상고심 (기저율)

목록의 **ㅅ · ㅍ · ㅎ 구간**을 보세요.

| # | 찾을 키워드 | 표 이름 | sht 코드 |
|---|---|---|---|
| 4 | **형사공판사건** | | |
| 5 | **상고** | | |
| 6 | **파기** | | |
| 7 | 항소심 | | |

**왜 필요한가**: Ⅶ 전원합의체 예측 기능의 기저율(base rate). 형사 상고심의 파기율이
얼마인지가 모든 예측의 출발점이다. 이 숫자가 없으면 예측은 근거 없는 확률이 된다.

> ⚠️ **「파기」 항목이 어느 표에도 없으면** API로는 기저율을 못 만든다.
> 그때는 사법연감 통계편 PDF로 전환한다. 무리하게 붙들지 말 것.

## 함께 확인해 주시면 좋은 것

### ① 년도 선택이 되는지
`*년도` 드롭다운에 연도 목록이 나오는지 확인해 주세요.
- 나온다 → **선택 가능한 연도 범위**를 알려주세요 (예: 2015~2024)
- 안 나온다 → 그대로 알려주세요

### ② 조회 결과 화면
표 하나를 골라 **[조회]** 를 눌러 결과를 스크린샷으로 주세요.
**[코드]** 탭을 누르면 JSON 원문이 보입니다 — 그게 더 유용합니다.

### ③ 활용가이드 문서
데이터 상세 페이지 하단의 **[참고문서]/활용가이드** 파일.
받아서 `docs/stats/` 에 올려주시면 **년도 파라미터의 정식 이름**을 확정할 수 있습니다.
(현재 `year=2024` 를 보내면 응답의 `statsYr` 이 빈 값으로 옵니다 — 파라미터 이름이 다른 듯)

## 태블릿에서 이 파일 직접 고치는 법

1. GitHub 저장소 → `docs/stats/SHT_CODES.md`
2. 오른쪽 위 **연필(✏️) 아이콘**
3. 표에 값 입력
4. 아래 **Commit changes** → 브랜치는 `claude/appeal-column-5hwjiy` 선택
5. 커밋

> 귀찮으면 **채팅으로 알려주셔도 됩니다.** 제가 이 파일을 채우겠습니다.
