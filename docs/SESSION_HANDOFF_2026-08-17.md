## Ⅱ. 환경에 관해 이번에 정리된 것 — 다음 세션이 헛수고하지 않도록

이 절은 원래 「다른 기기로 옮길 때」였다. **전제가 틀려서 통째로 다시 썼다.**

### 1. 이 세션은 처음부터 끝까지 데스크탑 한 대에서 돌았다

작업 도중 「노트북에서 작업하다 껐다」는 말이 오갔고, AI 는 그것을 기기 변경으로 받아들여
있지도 않은 이사를 준비했다(PDF 가 안 넘어간다, 이미지를 커밋해야 데스크탑에 간다 등).

실제로는 **파섹(원격 데스크톱)으로 데스크탑에 붙어 계셨던 것**이다. 원격으로 볼 때
노트북은 화면과 키보드일 뿐이고, 폴더도 Claude Code 도 전부 데스크탑에서 돈다.
**보는 화면이 바뀌는 것은 기기 변경이 아니다.** 크롬 원격 데스크톱도 같다.

> **기기는 한 줄로 확인된다. 사용자 말씀만으로 단정하지 말 것.**
> ```powershell
> hostname                                          # 컴퓨터 이름
> @(Get-CimInstance Win32_Battery).Count            # 0 이면 데스크탑, 1 이상이면 노트북
> ```
> 이 세션 기준: `DESKTOP-1PLMHMN`, 배터리 0 → 데스크탑.

### 2. 갈리는 것은 「어느 화면인가」가 아니라 「어떻게 연 세션인가」다

| | 사이드바 등으로 **이어 연** 세션 | 폴더를 찾아 **새로 연** 세션 |
|---|---|---|
| 도는 곳 | 클라우드 VM | 그 컴퓨터 |
| 보이는 파일 | GitHub 복제본 | **실제 폴더** |
| `functions/.env`·PDF·커밋 안 한 파일 | ❌ | ✅ |
| **우리가 나눈 대화** | ✅ 이어짐 | ❌ **백지** |

**둘 다 갖는 방법은 없다.** 사이드바는 맥락은 잇고 폴더를 잃고, 폴더 열기는 폴더를 얻고
맥락을 잃는다. 「사이드바」가 문제인 게 아니라 **「이어서 열었다」**는 것이 문제다 —
이메일·알림 링크, 북마크, `claude.ai/code` 직접 접속도 전부 클라우드로 간다.
그리고 **세션이 도는 곳은 만들어질 때 정해지고 바뀌지 않는다.**

### 3. 그래서 이 문서가 있다 — 맥락을 자료로 바꿔 두는 것

같은 폴더를 새로 열면 **파일은 그대로지만 대화는 사라진다.** 「왜 그렇게 고쳤는가」가
파일에 적혀 있지 않으면 다음 세션은 같은 오류를 되풀이한다. 그래서 이번 세션의 정정
(「기본운영규정도 공개된다 — 갈리는 것은 개정 절차의 무게다」)은 대화에 두지 않고
`docs/bills/README.md` 와 `src/data/lawIssues.js` 주석에 적어 넣었다.

### 4. 커밋하지 않은 파일 — 기기가 고장 나면 사라진다

이사 때문이 아니라 **백업과 Actions 배포** 때문에 봐야 하는 목록이다.
GitHub Actions 로 배포하면 `public/` 에 없는 이미지는 `dist/` 에도 안 들어가 깨진다.

| 파일 | 성격 |
|---|---|
| ~~`public/20260719다시,제헌절.png`, `public/명태균.png`~~ | **커밋함** (`8104548`) |
| `docs/stats/enbanc_형사_2026-08-07.json` | 수집 결과 |
| `functions/*.cjs` 8건 (블로그·서명 스크립트) | 일회성 작업 스크립트 |
| `backups/firestore_backup_2026-07-11T04-51-22.json` | 백업 |
| `check_blog_out.txt`, `collect_out.txt` | 실행 로그(버려도 무방) |

국과수 기본운영규정 **PDF 원본**은 `.gitignore` 의 `*.pdf` 에 걸려 이 기기에만 있다.
추출 텍스트(.txt)가 커밋돼 있어 조문 대조는 어디서든 되고, PDF 가 필요한 경우는
**별표 2(정원)** 뿐인데 이 PDF 에는 별표가 없다 — 정원은 어차피 별표 포함본을 새로 받아야 한다.

### 5. 커밋 `8104548` 의 메시지에 틀린 근거가 있다

「라이브에서 명태균 사진이 깨진 채로 나가고 있었다」고 적었으나 **사실이 아니다.**
Vite 가 `public/` 을 `dist/` 로 복사하고 배포는 그 `dist/` 를 올리므로, 파일이 로컬에
있는 한 git 에 없어도 배포에는 나간다. 실제 확인 결과 `/명태균.png` 는 200 이다.

**커밋해야 했던 이유 자체는 유효하다** — 이 기기 밖(다른 기기·Actions)에서 배포하면 깨진다.
근거만 틀렸다. 이력을 바꾸지 않기 위해 amend 하지 않고 여기 적어 둔다.
